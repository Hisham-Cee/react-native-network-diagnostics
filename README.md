# react-native-network-diagnostics

Network health and quality diagnostics for React Native: internet validation, captive portal, metered/constrained state and HTTPS latency. Built on TurboModules.

## Installation


```sh
npm install react-native-network-diagnostics
```


## Usage


```js
import { multiply } from 'react-native-network-diagnostics';

// ...

const result = multiply(3, 7);
```
